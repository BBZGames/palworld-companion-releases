# Palworld Companion – Downloads

Begleit-App für **Palworld 1.0** auf dem zweiten Bildschirm (Deutsch/Englisch). Sie liest deinen Steam-Spielstand automatisch – nur lesend – und sagt dir, was als Nächstes dran ist: freie Technik- und Statuspunkte, offene Quests, nächste Schritte, Boss-Pals in Reichweite und was die Pals in deiner Basis zusammen leisten.

## Download
Unter **[Releases](../../releases/latest)** die Datei `Palworld-Companion.exe` herunterladen und doppelklicken. Kein Python, keine Installation nötig. Ab Version 0.3.0 aktualisiert sich die App selbst.

Windows warnt beim ersten Start evtl. („Der Computer wurde durch Windows geschützt“), weil die Datei nicht signiert ist: **Weitere Informationen → Trotzdem ausführen**. Jede exe hat eine `.sha256`-Datei zum Prüfen.

## Hinweise
- Funktioniert mit Steam-Spielständen (`%LOCALAPPDATA%\Pal\Saved\SaveGames`). Xbox/Game Pass und dedizierte Server werden nicht unterstützt.
- Am Spielstand wird nichts verändert.
- Inoffizielles Fan-Werkzeug. Palworld ist eine Marke von Pocketpair, Inc. Spieldaten nach paldb.cc, palworld.wiki.gg, palworld.fandom.com und palpedia.ru.

Dieses Repo enthält nur die fertigen Programmdateien.
